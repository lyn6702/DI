# 옷장패션 데이터 정제 보고서

## 1. 데이터 개요
- 행/열: 1,500 × 7
- 주요 컬럼: order_id, customer_age, category, channel, price, quantity, amount, return_amount

## 2. 진단 결과
- 결측: amount 3.4%, price 0.33%, ...
- 이상치(IQR): customer_age(999·0, 18건), quantity(200, 1건), amount(50,000,000, 145건)
- 의심되는 결측 유형: amount는 app 채널에 쏠림 → MAR

## 3. 처리 결정과 근거
| 이슈 | 결정 | 근거 | 한계 |
|---|---|---|---|
| price 결측 | 카테고리별 중앙값 대체 | 비율이 약 0.3%로 적고 상품가격은 카테고리와 연관이 있어 카테고리별 가격대로 보존 | 표본이 적어 카테고리 통계 불안정 |
| amount 결측 | 채널별 중앙값 대체 | app의 결측 비율이 높아 MAR 가설 부합 | 다른 원인을 검토 안함 |
| customer_age = 999, 0 | NaN 표시 -> 중앙값 대체 | 물리적으로 불가능하여 입력 실수로 추정됨 | 외부 인증 데이터가 없음 |
| quantity = 200 | NaN 표시 -> 중앙값 대체 | 일반 소비자 도메인 외 값으로 추정 | 만약 도매 가능 고객이면 제거가 손실이 됨 |
| amount = 50,000,000 | 유지 + 플래그 | 1건의 비즈니스적 가능성 보존 | 도매면 별도 분석 필요 |
