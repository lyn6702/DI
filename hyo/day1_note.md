## 1. 자료형과 컬렉션

- **자료형** = 값 **하나**를 담는 것
- **컬렉션** = 값 **여러 개**를 담는 그릇

### 자료형 4가지

| 자료형 | 뜻 | 예 |
|---|---|---|
| int | 정수 | 나이, 건수 |
| float | 실수 | 평균, 비율 |
| str | 문자열 | 지역, 채널 |
| bool | 참/거짓 | 조건 결과 |

### 컬렉션 4가지 ⭐

| 컬렉션 | 기호 | 순서 | 수정 | 중복 | 핵심 |
|---|---|---|---|---|---|
| 리스트 | `[ ]` | O | O | O | 순서대로 쌓기 |
| 튜플 | `( )` | O | **X** | O | 못 바꿈 (좌표) |
| 집합 | `{ }` | X | O | **X** | 중복 제거 |
| 딕셔너리 | `{k:v}` | O | O | key X | 이름표로 찾기 |

- 리스트 vs 튜플 → **수정 가능 여부**
- "어떤 종류가 있나?" → **집합**
- 계좌번호처럼 앞자리 0이 중요하면 → **문자열**

## 2. 함수와 클래스

| 개념 | 비유 | 핵심 |
|---|---|---|
| 함수 | 자판기 | 입력 → 처리 → 출력, **재사용** |
| lambda | — | 이름 없는 한 줄 함수 |
| 클래스 | 붕어빵 틀 | 데이터 + 작업을 묶은 **설계도** |
| 객체 | 붕어빵 | 클래스로 찍어낸 것 |
| 메서드 | — | 객체에 붙은 작업 |

- `def` = 함수 만들기 / `return` = 결과 돌려주기 (없으면 **None**)
- `df.head()` → `df`는 **객체**, `.head()`는 **메서드**
- 분석가는 클래스는 **사용**, 함수는 **직접 만든다**

## 3. NumPy

- **벡터화**: 반복문 없이 배열 **전체에 한 번에** 계산 → 빠름 (내부가 C 언어)
- **브로드캐스팅**: 크기가 달라도 자동으로 맞춰 계산
- 배열은 **같은 자료형**만 담음

### 리스트 vs 배열 ⭐

| | `* 2` 결과 |
|---|---|
| 리스트 | 내용이 **두 번 반복** |
| 배열 | 각 값이 **2배** |

- 조건을 걸면 → **불리언 배열**
- 불리언의 `.sum()` → **True 개수** (True = 1)
- `axis=0` → 세로(**열별**) / `axis=1` → 가로(**행별**)

## 4. pandas

- **Series** = 열 하나 (1차원)
- **DataFrame** = Series가 모인 표 (2차원)
- **NumPy = 엔진, pandas = 운전석** (DataFrame의 각 열은 NumPy 배열)

### NumPy vs pandas ⭐

| | NumPy | pandas |
|---|---|---|
| 자료형 | 한 종류만 | 열마다 달라도 됨 |
| 이름표 | 없음 | 행 인덱스, 열 이름 |
| 강점 | 숫자 계산 | 실데이터 (결측·혼합형) |

### 기본기 4가지

**선택 · 필터 · 정렬 · 파생 컬럼**

- 필터 `df[조건]` = 데이터 분석의 **80%**
- 조건 여러 개 → `&`(그리고), `|`(또는), **각 조건은 괄호로**
- `notna()` = `isnull()`의 반대

> ⚠️ `.mean()`은 결측(NaN)을 **조용히 빼고** 계산 → 그래서 진단이 먼저!

## 5. 구조·품질 진단 ⭐⭐

### 건강검진 3종 세트 (이 순서로!)

| 순서 | 도구 | 비유 | 알려주는 것 |
|---|---|---|---|
| 1 | `shape` | 키·몸무게 | (행, 열) |
| 2 | `info()` | X-ray | 자료형 + 결측 아닌 개수 |
| 3 | `describe()` | 혈액검사 | 평균·min·max 등 |

### 추가 진단

| 도구 | 찾는 것 |
|---|---|
| `isnull().sum()` | 결측 |
| `duplicated().sum()` | 중복 |
| `unique()` | 표기 혼재 |

### 오염 5종 ⭐

| 문제 | 예시 | 발견 도구 |
|---|---|---|
| 결측치 | 빈칸 | `isnull()` |
| 이상치 | 나이 999, 음수 | `describe()` |
| 표기 혼재 | app / APP / 서울·Seoul | `unique()` |
| 날짜 포맷 혼재 | 2025-01-01 / 20250101 | `info()` |
| 중복 행 | 같은 주문 2번 | `duplicated()` |

- `info()`에서 날짜가 **object** → 문자열로 저장된 상태
- `'app'`과 `'app '`은 컴퓨터에게 **다른 값** → 집계가 어긋남
- 에러 메시지는 **맨 아랫줄**부터 읽기

## 6. 시각화 ⭐

> 차트 고르기 전에 **"무엇을 판단할 것인가"**부터 정한다

| 목적 | 차트 |
|---|---|
| **분**포 | **히**스토그램, 박스플롯 |
| **관**계 | **산**점도 |
| **추**이 | **선** 그래프 |
| **비**교 | **막**대 그래프 |

🧠 **분·관·추·비 → 히·산·선·막**

### 읽는 법

- 박스플롯 **상자** = 가운데 50%, **상자 밖 점** = 이상치 후보
- 산점도 **우상향** = 양의 관계
- 이상치 하나가 그래프를 **납작하게 뭉갠다** → **진단이 시각화의 전제**

## 7. EDA

- **EDA** = 탐색적 데이터 분석. 처음 만난 데이터의 구조·품질·패턴을 살펴보는 과정
- 순서: **구조 → 품질 → 패턴 → 요약**

### 리포트 5항목

1. 데이터 개요
2. 구조 진단
3. 품질 진단
4. 패턴
5. 다음 분석 제안 (**판단 근거** 필수)

## ✅ 빈칸 퀴즈

| 질문 | 답 |
|---|---|
| 순서 O, 수정 O인 컬렉션 | 리스트 |
| 중복이 자동으로 사라지는 컬렉션 | 집합 |
| return이 없는 함수의 결과 | None |
| 반복문 없이 전체에 한 번에 계산 | 벡터화 |
| 열마다 자료형이 달라도 되는 도구 | DataFrame |
| 처음 받은 데이터 진단 3종 | shape → info → describe |
| describe의 max가 999면 | 이상치 |
| 값의 종류를 확인하는 함수 | unique() |
| 두 변수의 관계를 보는 차트 | 산점도 |
| 차트 고르기 전 먼저 정할 것 | 판단할 질문 |
