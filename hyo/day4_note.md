# 📒 문자열과 날짜, 쓸 수 있는 형태로 — 정리노트

> ⭐ **핵심 한 줄:** 처리하기 전에 **원본의 패턴부터 눈으로 확인**한다. 생김새를 봐야 올바른 방법을 고를 수 있다.

```text
str 정제 → 검색·분리 → 정규표현식 → 날짜 파싱 → dt 부품 → 리샘플링·이동평균
(공백·대소문자) (조각 꺼내기) (제각각 패턴) (문자열→날짜) (연·월·요일) (시간 단위로 묶기)
```

---

## 1. 문자열 정제 — `.str` 기초 ⭐

- 컴퓨터에게는 **공백 하나, 대문자 하나도 다른 값**
- `'서울'`, `' 서울 '`, `'Seoul'` → 따로 집계됨
- `repr()`로 보면 숨은 공백이 보임 → **정제 전 원본 확인 습관**

### `.str` 접근자

- 문자열 컬럼에 `.str`을 붙이면 → **컬럼 전체에 한 번에** 적용 (문자열판 벡터화)

| 기능 | 하는 일 |
|---|---|
| `.str.strip()` | 앞뒤 **공백 제거** |
| `.str.lower()` / `.upper()` | 소문자 / 대문자 통일 |
| `.str.replace(a, b)` | a를 b로 **치환** |
| `.str.len()` | 글자 수 |

### 정제 순서 🧠

**공백 제거(strip) → 대소문자 통일(lower) → 표기 치환(replace)**

- `.str.strip().str.lower()` → 점으로 이어 붙이기 = **메서드 체이닝**
- **왼쪽부터 차례로** 적용
- 이어 붙일 때마다 `.str`을 **다시** 붙여야 함
- **정제는 올바른 집계의 전제** (groupby 전에 반드시)
- 이메일·아이디는 보통 **소문자**로 통일

## 2. 검색·분리·추출

| 기능 | 하는 일 | 결과 |
|---|---|---|
| `.str.contains("a")` | 포함하는가 | 불리언 |
| `.str.startswith("a")` | 그걸로 시작하는가 | 불리언 |
| `.str.split("@")` | 기준 글자로 쪼개기 | 리스트 |
| `.str.split("@").str[1]` | 쪼갠 뒤 N번째 조각 | 문자열 |
| `.str[0:3]` | 위치로 자르기 (슬라이싱) | 문자열 |

- `contains` 결과는 **불리언** → `df[조건]` 필터에 바로 사용
- `split` → **구분자가 일정**할 때 (이메일 `@`, 경로 `/`)
- 슬라이싱 → **형식이 일정**할 때만 안전
- 형식이 제각각이면 → **정규표현식** 필요

---

## 3. 정규표현식 (regex) ⭐⭐

- **자리는 제각각이지만 규칙은 있는** 패턴을 뽑는 도구
- 정확한 글자 대신 **종류와 개수**로 묘사하는 언어
- 패턴 앞에 **`r"..."`** (raw string) → 역슬래시 깨짐 방지

### 기호 ⭐

| 기호 | 뜻 |
|---|---|
| `\d` | **숫자** 한 개 |
| `\w` | 글자·숫자·밑줄 한 개 |
| `+` | 앞의 것 **1개 이상** |
| `[...]` | 괄호 안 글자 **중 하나** |
| `[^...]` | 괄호 안 글자가 **아닌** 것 |
| `.` | **아무** 글자 한 개 |
| `()` | **뽑아낼** 부분 (그룹) |
| `(?P<이름>...)` | **이름 붙은** 그룹 → 그 이름이 컬럼명 |

### 예시로 외우기

| 패턴 | 뜻 |
|---|---|
| `\d+` | 숫자가 1개 이상 이어진 것 |
| `[A-Z]+` | 대문자 묶음 |
| `[^0-9]` | 숫자가 아닌 글자 |

### 함수

| 함수 | 하는 일 |
|---|---|
| `.str.extract(r"(패턴)")` | 그룹 `()` 부분을 **새 컬럼**으로 |
| `.str.findall(r"패턴")` | 일치하는 **모든** 조각을 리스트로 |
| `.str.replace(r"패턴", "", regex=True)` | 패턴 부분 **치환·삭제** |
| `.str.contains(r"패턴", regex=True)` | 패턴이 있는지 불리언 |

- 전화번호 숫자만 남기기 → `[^0-9]`를 `""`로 치환

### 언제 무엇을? ⭐

| 상황 | 도구 |
|---|---|
| 구분자·위치가 **일정** | `split`, 슬라이싱 |
| 단순히 "포함하는가" | `contains` |
| **자리가 제각각**인 패턴 | 정규식 `extract` / `replace` |
| "숫자만", "특정 형식만" | 정규식 |

- 🧠 **"split으로 되나?" 먼저 → 안 되면 정규식** (같은 결과면 읽기 쉬운 쪽)

## 4. 날짜 파싱 ⭐⭐

- 날짜처럼 보이는 **문자열 ≠ 날짜** → 계산 불가
- **파싱** = 글자를 날짜로 해석하는 것 → `pd.to_datetime()`
- 문자열이면 dtype **`object`**, 날짜가 되면 **`datetime64`**

### `pd.to_datetime` 옵션

| 옵션 | 하는 일 | 언제 |
|---|---|---|
| (기본) | 형식 **자동 추론** | 형식이 깔끔할 때 |
| `format="..."` | 형식 **직접 지정** (가장 정확·빠름) | 형식을 알 때 |
| `format="mixed"` | 행마다 **각자 추론** | 포맷이 섞였을 때 |
| `errors="coerce"` | 변환 실패 → **NaT** | 오류값이 섞였을 때 |

### 형식 기호

| 기호 | 뜻 | 예 |
|---|---|---|
| `%Y` | 4자리 연도 | 2025 |
| `%m` | 2자리 월 | 01 |
| `%d` | 2자리 일 | 12 |
| `%H:%M:%S` | 시:분:초 | 10:15:32 |
| `%b` | **영문 월 약자** | Jan |

### NaT ⭐

- **NaT** = Not a Time = **날짜판 결측치** (숫자의 NaN)
- `coerce` 가치: 코드는 **멈추지 않고**, 실패 건수는 **셀 수 있음**
- 실패 건수는 **품질 지표**로 보고 ("2,000건 중 12건 실패, 0.6%")
- 날짜 파싱은 종종 **문자열 정제와 한 몸** (구분자 통일 → format 지정)

## 5. `dt` 기능 — 날짜의 부품 꺼내기 ⭐

- 🧠 **문자열엔 `.str`, 날짜엔 `.dt`**

| 코드 | 부품 |
|---|---|
| `.dt.year` | 연도 |
| `.dt.month` | 월 |
| `.dt.day` | 일 |
| `.dt.hour` | 시 |
| `.dt.dayofweek` | 요일 번호 (**0=월 … 6=일**) |
| `.dt.day_name()` | 요일 이름 (영문) |
| `.dt.date` | 시각 뺀 날짜 |

- `dayofweek`는 **월요일이 0** ⭐
- 숫자 → 정렬·집계에 편함 / 이름 → 그래프 라벨에 편함
- 부품 컬럼 → `groupby`에 넣어 요일별·시간대별 분석

### 무엇을 보나

| 부품 | 분석 |
|---|---|
| `.dt.hour` | 시간대별 트래픽 |
| `.dt.dayofweek` | 요일 패턴 |
| `.dt.month` | 계절성 |

- 파생 플래그: 주말 = `dayofweek >= 5`, 영업시간 = `9 <= hour < 18`

## 6. 리샘플링·이동평균 ⭐

| 개념 | 뜻 |
|---|---|
| **리샘플링** (resample) | 시간 **눈금 간격**을 바꿔 묶기 (초 → 일) |
| **이동평균** (rolling) | 최근 N개의 평균으로 **부드럽게** |

- ⚠️ `resample`은 **날짜가 인덱스**여야 동작 → 먼저 `set_index("날짜열")`

| 코드 | 하는 일 |
|---|---|
| `.resample("D").sum()` | 하루 단위 합계 |
| `.resample("W").sum()` | 주 단위 합계 |
| `.resample("h").count()` | 시간 단위 개수 |
| `.rolling(7).mean()` | 최근 7개 이동평균 |

### 빈도 문자

| 문자 | 단위 |
|---|---|
| `"h"` | 시간 |
| `"D"` | 일 |
| `"W"` | 주 |
| `"ME"` | 월말 |

- `count()` = **건수** / `sum()` = **합계**
- 이동평균 앞 N−1개는 **NaN** (최근 N개를 못 채워서)
- 너무 잘게 자르면 **노이즈**, 너무 크게 자르면 **디테일 사라짐**
- 🧠 **목적이 시간 단위를 정한다** (시간대별 → `"h"`, 일 추세 → `"D"`, 월 KPI → `"ME"`)

## 7. 종합 실습 — 웹 로그 파싱

로그 한 줄 = 하나의 문자열

```text
203.0.113.5 - - [12/Jan/2025:10:15:32] "GET /products/123 HTTP/1.1" 200 1024
    IP              접속 시각          방식    요청 경로           상태  크기
```

### 순서 🧠

**원본 관찰 → 정규식 파싱 → 날짜 변환 → 부품·집계** (= Part 1~6 순서)

1. 이름 붙은 그룹 `(?P<이름>...)`으로 6개 필드 **한 번에 추출**
2. 시각은 `%d/%b/%Y:%H:%M:%S`로 파싱, 상태·크기는 **숫자로 변환**
3. `.dt.hour`로 시간 부품, `value_counts()`로 인기 경로
4. `resample("h")`로 시간대별 트래픽

- 오류 응답 = **status ≥ 400** (404 없음, 500 서버 오류)
- 불리언의 `.mean()` = **True 비율** → 오류율

## 8. 상황별 도구 고르기

| 신호 | 도구 |
|---|---|
| 서울 / Seoul / ' 서울 ' 혼재 | `strip` + `replace` |
| `@` 뒤 도메인만 필요 | `split("@").str[1]` |
| 전화번호·코드처럼 자리 제각각 | 정규식 `extract` / `replace` |
| 날짜가 문자열(object) | `pd.to_datetime(errors="coerce")` |
| 요일별·시간대별이 궁금 | `.dt.dayofweek`, `.dt.hour` + `groupby` |
| 일·주 단위 추세 | `resample` + `rolling` |

## ✅ 빈칸 퀴즈

| 질문 | 답 |
|---|---|
| 앞뒤 공백 제거 + 소문자 통일 | `.str.strip().str.lower()` |

| 자리 제각각인 패턴을 뽑는 도구 | 정규표현식 |
| 숫자 1개 이상 | `\d+` |
| 숫자가 아닌 글자 | `[^0-9]` |
| 뽑아낼 부분을 묶는 기호 | `()` |
| 정규식 앞에 붙이는 것 | `r` (raw string) |
| 일치하는 모든 조각을 리스트로 | `findall` |
| 문자열을 날짜로 바꾸는 함수 | `pd.to_datetime` |
| 오류값을 NaT로 만드는 옵션 | `errors="coerce"` |
| 포맷이 섞였을 때 format 값 | `"mixed"` |
| NaT의 뜻 | 날짜판 결측치 (Not a Time) |
| 영문 월 약자 기호 | `%b` |
| 날짜에 붙이는 접근자 | `.dt` |
| `dayofweek`에서 월요일 | 0 |
| resample 전에 필요한 것 | 날짜를 인덱스로 (`set_index`) |
| 하루 단위 합계 | `resample("D").sum()` |
| 최근 7개 이동평균 | `rolling(7).mean()` |
| 오류 응답 기준 | status ≥ 400 |
